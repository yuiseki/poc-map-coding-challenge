# 03: Point in Polygon (ポイント・イン・ポリゴン)

ある地点が指定した多角形の内側にあるかどうかを判定してください。

## 背景

「この座標は東京都内か？」「このユーザーはサービス提供エリア内か？」など、  
GIS で最も頻繁に使われる空間演算のひとつです。  
**レイキャスティング法** で実装できます。

## タスク

点 `point` が多角形 `polygon` の内側にある場合は `true`、  
外側にある場合は `false` を返してください。

## 制約

- `polygon` は頂点の配列（最初と最後の頂点が同じ閉じたリングでも、そうでなくてもよい）
- ポリゴンは自己交差しない単純な多角形
- 境界上の点は `true` または `false` どちらでもよい（テストでは境界上の点を使わない）
- 穴（hole）は考慮しなくてよい

## 入出力例

```
point   = [139.7, 35.7]   // 東京駅付近
polygon = [[139.6, 35.6], [139.8, 35.6], [139.8, 35.8], [139.6, 35.8]]
→ true（矩形の内側）
```

```
point   = [135.5, 34.7]   // 大阪
polygon = [[139.6, 35.6], [139.8, 35.6], [139.8, 35.8], [139.6, 35.8]]
→ false（矩形の外側）
```

## レイキャスティング法（ヒント）

点から水平に右方向へレイを飛ばし、ポリゴンの辺と交差する回数が  
**奇数** なら内側、**偶数** なら外側。

## 関数シグネチャ

```typescript
export function pointInPolygon(
  point: [number, number],
  polygon: [number, number][]
): boolean
```
